# Schriften

**Inter** (variabel, 100–900) — SIL Open Font License 1.1.
Lizenztext liegt als `INTER-LICENSE.txt` bei.

Bewusst **lokal** ausgeliefert: kein Google-CDN, kein externer Request, keine
IP-Übertragung an Dritte. Eingebunden per `@font-face` in `styles.css`.

Beträge und Kennnummern nutzen `font-variant-numeric: tabular-nums` in derselben
Familie — es wird keine zweite Schrift für Ziffern geladen.
